# Проект «Шифратор банковских данных»

## Описание проекта
Программа маскирует номера банковских карт и счетов, преобразует даты в читаемый формат, а также умеет фильтровать и сортировать список финансовых операций по статусу и дате.

# Установка и запуск

## 1. Клонируем репозиторий
git clone https://github.com/artaste-ui/bank-card-encoder.git

## 2. Переходим в папку проекта
cd PythonProject7

## 3. Для работы функций запускаем программу
python main.py

# Примеры работы функций:

## Функция get_mask_card_number:
- Вводим номер карты: 4536457836734
- Выведет: 453645***6734

## Функция get_mask_account:
- Вводим счёт карты: 2347694
- Выведет: ***7694

## Функция mask_account_card:
- Вводим полное наименование карты: тип и номер, например Visa Platinum 425345653456
- Выведет: Visa Platinum 425345**3456

## Функция get_date:
- Вводим дату в формате '2024-03-11T02:26:18.671407'
- Выведет: '11.03.2024'

## Функция filter_by_state:
- Изначально данн список словарей в котором в ключе "state" значением может быть или EXECUTED или CANCELED
- Выведет: список словарей без словаря со значением ключа CANCELED

## sort_by_date:
- Из того же изначально данного словаря отсортирует уже по возрастанию и убыванию по параметру "date"
